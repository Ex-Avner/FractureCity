## 🎯 Coherence — Public Launch

**Target: Friday 2026-07-17** (≈ 6 weeks from today, 2026-06-08)

itch.io. Pay-what-you-want, $0 minimum. Standalone HTML build + macOS `.app`.

### Pre-launch polish (4 weeks of work, 2 weeks of buffer)

- [ ] Controller (gamepad API) — refactor input through an abstraction, then add. ~2 days.
- [ ] Save system — single-slot run autosave, resumable from main menu. ~2 days.
- [ ] Music — one composed track for the title, one for The Mirror, one for the ending cutscene. Commission or CC-licensed. ~1 day to integrate.
- [ ] One full playthrough QA pass (sword / gun / magic, each start-to-end). Catch the surface bugs. ~3 days.
- [ ] The Look System rolled out to every section (currently uneven). ~3 days.
- [ ] Cinematic trailer — 60 seconds. Title → prelude lightning → S0–S5 montage → Mirror → void → "you came home." ~2 days.
- [ ] itch.io page — copy, screenshots, GIFs, system reqs. ~1 day.
- [ ] One reverse-pass playtest by someone who didn't make it. ~1 evening.

### Launch-day checklist

- [ ] Build the standalone HTML (sync command in CHECKPOINT.txt).
- [ ] Code-sign and notarize the .app (or document the "right-click → open" workaround).
- [ ] Upload to itch.io.
- [ ] Post on r/IndieDev, r/WebGames, Bluesky, Mastodon.
- [ ] Pin the trailer on personal socials.

### Post-launch (Week 1 after)

- Read every comment. Patch only what's broken.
- Day 7: collect feedback into a single doc, plan v1.1.
