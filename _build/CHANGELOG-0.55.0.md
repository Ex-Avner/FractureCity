# 0.55.0 — Cast Studio

Adds a local character creator with a live 3D preview, appearance controls, authored backstories and dialogue, and resident / ally / armed rogue roles. Spawn, command, revive and dismiss characters through the in-game menu. Allies follow and defend; rogues attack, respecting peaceful mode. Store up to 32 designs and 12 placements per city; export/import designs for backup. Existing saved cities restore their own cast.

Includes the 0.54 zombie pursuit, animation and salvage weapon update. Browser tests cover editor use, story text, supported spawning, following, holding position, combat, peaceful mode, death/revival, dismissal, invalid imports, saved-city reload and mobile layout.
