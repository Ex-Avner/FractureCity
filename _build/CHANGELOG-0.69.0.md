# v0.69.0 — Common Ground atrium

Common Ground now has an open arrival court beneath an elliptical illuminated canopy. Four solid supports, batched radial ribs, cooler paving, continuous approach inlays and edge seating establish a recognizable public space.

The Reading Wall is lower, with a smaller passage plaque. The obstructing arbour is removed. Tree crowns use rounded meshes above solid trunks. Pool edges sit flush with the ground, and plaza tiles no longer cover the garden soil. Flowers, moving water, fireflies, daily passages and the bundled/online classics reader remain.

Music and theory kiosks move to the sides of the arrival court and use smaller, coordinated displays. The gallery remains on the south edge. Local Makers’ Mile entry and newly created online city seats face the court; saved online positions remain unchanged.

Validation: browser reading-garden suite (including full centre walk, solid supports, both relocated kiosk interactions, daily passage, bundled novel, mocked Gutenberg search/mirror fetch and phone reader); news-hub browser suite (news, persistent gallery posting and touch-only phone navigation); server city-online and Main Beta suites (six tests); JavaScript syntax and diff checks. Screenshots inspected at street and elevated viewpoints.

Limits: this changes the authored Common Ground district, not the surrounding procedural skyline. The canopy is overhead decorative architecture, not a new walkable rooftop. Online book tests use fixture catalogue/text responses; no new claim about live mirror availability. No deployment or ZIP packaging performed.
