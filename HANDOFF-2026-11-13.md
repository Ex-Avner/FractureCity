## What went wrong today, so it is not repeated

- The first Mirror Hour shipped tested only in software rendering. On the owner's Mac it drew large black blocks across the sky and lagged badly.
- Probable cause of the black: undefined shader maths (negative `pow` bases, reversed `smoothstep` edges) producing invalid pixels that the bloom pass smeared. Not reproduced. Fixed by clamping.
- Probable causes of the lag: per-pixel aurora noise, an extra scene light, shadow passes for the new street meshes. All three removed or cheapened.
- **Rule from now on: test on the owner's real GPU before handing over.** The Claude desktop app has a built-in browser on the Mac. Use it. Headless software GL proves nothing about speed or about undefined shader behaviour.
- Whether the lag was night-only or all day is still unanswered. If it lags by day, cut `street-fabric.js` back (cars are the largest triangle share).

## The school: what is there

- The Free College is one course, `thinking-101`, defined as a single object in `college-content.js` (`window.FCCollegeContent`, also `module.exports` for the server).
- `free-college.js` and `college-progress.js` read that one global.
- The server (`server/college.cjs`) grades it and stores one row per account: `college_progress(account_id PRIMARY KEY, payload)`.
- Entry is the Mnemonic Archive, plus Tools and the phone menu. See `FREE-COLLEGE.md` for the assessment contract and the claims that must not be made (no accreditation, no faculty review).

## The school: what "more classes" requires

1. A course registry in place of the single object, with `thinking-101` kept at its current id and version.
2. Progress stored per course. The table can stay: put `{courses:{<id>:…}}` inside `payload` and migrate an old payload on first read. Same for the solo `localStorage` key.
3. Server grading keyed by course id.
4. A catalogue screen before the course screen.
5. The courses themselves. Each one at the current standard is about 30 KB of authored text: six units, thirty unit questions, a twelve-question final with a dossier, a project. This is the real cost.
6. Existing tests to keep green: `college.test.cjs`, `college-server.test.cjs`, `college-browser.test.cjs`, `college-online-browser.test.cjs`.

Decide with the owner first: which subjects, and whether every class is a full course or some are short seminars (one reading, a few questions, local progress only). Short seminars avoid steps 2 and 3 entirely.
